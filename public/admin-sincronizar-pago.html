🔄 Sincronizar pago

Consultar y sincronizar contra Mercado Pago

Plan B para cuando el webhook de Mercado Pago no actualizó un pedido a tiempo (o falló): esto consulta el estado real del pago directo contra la API de Mercado Pago y actualiza el pedido si corresponde — exactamente lo mismo que hubiera hecho una notificación que sí hubiera llegado y funcionado.

También acepta el id numérico interno del pedido. Si lo dejás vacío, se busca automáticamente el pago asociado a este pedido en Mercado Pago (por external_reference). Si tenés el collection_id de la URL de vuelta del comprador, ponerlo acá apunta directo a ese pago puntual.
